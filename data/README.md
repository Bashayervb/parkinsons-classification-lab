# Data source

Download `parkinsons_disease_data.csv` from Rabie El Kharoua's dataset:
https://www.kaggle.com/datasets/rabieelkharoua/parkinsons-disease-dataset-analysis

Place it here without renaming. A Kaggle account may be required by the publisher's interface. The dataset is synthetic educational data, licensed by the publisher under CC BY 4.0. Credit the publisher when reusing it.

A copy of the user-supplied file is included only in the downloadable project bundle for reproducibility. `.gitignore` excludes the CSV from commits. No names or contact details are present, and the supplied bytes matched the publisher's downloadable CSV. `PatientID` is never a model input.
